# 02 指标口径

口径的意思：每个指标**具体怎么算**。同一个“转化率”，按访问算还是按用户算、分母包不包括跳出的访问，结果会差很多。所有规则只在明细层实现一次（`sql/03_dwd.sql`），后面各层只做加总。

## 1. 基础对象

| 名称 | 定义 | 来源 |
|---|---|---|
| 访问（session） | 用户打开网站到离开的一次浏览过程，一行 `website_sessions` | `dwd.fact_session` |
| 浏览（pageview） | 一次访问里打开的一个页面 | `dwd.fact_pageview` |
| 订单 | 一次下单；一个访问最多一笔订单（质量检查已验证） | `dwd.fact_order` |
| 订单明细 | 订单里的一件商品；每笔订单恰好 1 件主商品，其余为交叉销售商品 | `dwd.fact_order_item` |

## 2. 指标

| 指标 | 公式 | 说明 |
|---|---|---|
| 访问数 | COUNT(访问) | |
| 订单数 | COUNT(订单) | 按**所属访问的开始时间**归到日期/月份（`fact_session.session_date`），使转化率的分子分母在同一时间段 |
| 转化率（CVR） | 订单数 ÷ 访问数 | 按访问算，不按用户算 |
| 收入 | SUM(订单金额 price_usd) | 美元，未扣退款 |
| 毛利 | 收入 − 商品成本（cogs_usd） | 不含广告、运费等费用 |
| 毛利率 | 毛利 ÷ 收入 | |
| 客单价（AOV） | 收入 ÷ 订单数 | |
| 每次访问收入（RPS） | 收入 ÷ 访问数 | = 转化率 × 客单价；**付费广告每次点击的出价不应超过这个值**（还要扣成本和利润目标） |
| 跳出率 | 只看了 1 个页面就离开的访问 ÷ 访问数 | |
| 商品退款率 | 退款件数 ÷ 售出件数 | 按**下单月份**归属，用来看“某个月卖出的这批货”质量如何；见第 5 节的截尾说明 |
| 交叉销售率 | 含某个附加商品的订单 ÷ 该主商品的订单 | 只统计最后一款商品上架之后（程序自动取 dim_product 里最晚的上架时间，本数据为 2014-02-05），所有商品都在售的时期 |

## 3. 渠道分组

| 渠道 | 规则 | 渠道类型 |
|---|---|---|
| G搜索-非品牌词 | utm_source = gsearch 且 utm_campaign = nonbrand | 付费拉新 |
| B搜索-非品牌词 | utm_source = bsearch 且 utm_campaign = nonbrand | 付费拉新 |
| 社交广告 | utm_source = socialbook（2014 年试投） | 付费拉新 |
| G搜索-品牌词 | utm_source = gsearch 且 utm_campaign = brand | 付费品牌词 |
| B搜索-品牌词 | utm_source = bsearch 且 utm_campaign = brand | 付费品牌词 |
| 自然搜索 | 没有 utm 标记，但有来源网址（http_referer） | 免费流量 |
| 直接访问 | 没有 utm 标记，也没有来源网址（直接输入网址、收藏夹） | 免费流量 |

- **非品牌词**：用户搜“毛绒玩具”这类通用词时展示的广告，用来**拉新客**；
- **品牌词**：用户搜公司名字时展示的广告，说明用户**已经知道这个品牌**；
- “付费品牌词 + 免费流量”的占比上升，说明品牌认知在变强、对拉新广告的依赖在下降。
- 原始数据里没有标记的值写成文字 `"NULL"`（83,328 行），明细层统一转成空值。

## 4. 页面和漏斗

| 规则 | 定义 |
|---|---|
| 落地页 | 访问中的**第一个**页面（浏览编号最小的那个） |
| 页面类型 | 落地页（/home、/lander-*）→ 商品列表（/products）→ 商品详情（4 个商品页）→ 购物车（/cart）→ 填写配送（/shipping）→ 填写支付（/billing、/billing-2）→ 下单成功（/thank-you-for-your-order） |
| 漏斗某一步的转化率 | 到达下一步的访问数 ÷ 到达这一步的访问数（只要访问中出现过该页面就算到达） |

## 5. 时间和截尾

- **不完整月份按数据实际覆盖的日期自动判断**：某月第一条访问晚于 1 号、或最后一条早于月末，就标为 `is_partial = 1`（`ads.kpi_monthly` 里有 `first_day`、`last_day` 两列可以核对）。本数据从 2012-03-19 开始、到 2015-03-19 结束，所以 2012-03 和 2015-03 被标出；以后追加新数据不需要改脚本。季度不足 3 个月、年度不足 12 个月也标为不完整。
- **“最近一个完整年度”** 同样从数据推算（本数据是 2014 年），漏斗、新老访客、时段分析和看板标题都用它，不写死年份。
- **除零保护**：所有比率的分母都写成 `NULLIF(分母, 0)`，分母为 0 时结果是空值，不会报错，也不会被误读成 0。
- 退款通常发生在下单后 9 天左右，最长 16 天。所以 **2015 年 3 月上旬之后下的单，可能还没来得及退款**，这几周的退款率会偏低。
- 星期几：周一 = 1，周日 = 7。
