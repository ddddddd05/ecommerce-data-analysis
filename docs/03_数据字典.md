# 03 数据字典

## 数据分层

```
data/raw/*.csv ──prepare_staging.py──► data/staging/*.tsv（只改文件格式）
        │
        ▼ BULK INSERT
ods  原始层   6 张表，全部 VARCHAR，和源文件一模一样
        │  02 质量检查（28 项阻断 + 6 项警告 + 3 项信息；各层加工后另有 8 项层间核对）
        ▼
dwd  明细层   类型转换、空值处理、派生字段（渠道、落地页、漏斗、是否下单、退款）
        ▼
dws  汇总层   按天 / 月 / 渠道 / 设备 / 商品预先汇总
        ▼
ads  应用层   每张表回答一个业务问题，报告和看板只读这一层
dq   质量     导入记录 load_log、检查结果 check_results
```

## 原始表（来自 Maven Analytics）

| 表 | 行数 | 一行代表 | 主键 | 关联 |
|---|---|---|---|---|
| website_sessions | 472,871 | 一次访问 | website_session_id | user_id |
| website_pageviews | 1,188,124 | 一次页面浏览 | website_pageview_id | website_session_id → sessions |
| orders | 32,313 | 一笔订单 | order_id | website_session_id → sessions，primary_product_id → products |
| order_items | 40,025 | 订单里的一件商品 | order_item_id | order_id → orders，product_id → products |

| products | 4 | 一款商品 | product_id | |

## 明细层

### dwd.fact_session（一行 = 一次访问）

| 字段 | 类型 | 含义 |
|---|---|---|
| session_id | INT | 访问编号（主键） |
| user_id | INT | 用户编号 |
| session_start / session_date / session_month | DATETIME / DATE / DATETIME | 访问开始时间、日期、所在月份第一天 |
| is_repeat_session | BIT | 1 = 这个用户之前来过 |
| utm_source / utm_campaign / utm_content | VARCHAR | 广告来源、广告系列、广告素材；没有则为空 |
| device_type | VARCHAR | desktop 电脑 / mobile 手机 |
| http_referer | VARCHAR | 来源网址；没有则为空 |
| channel | NVARCHAR | 渠道（7 类，规则见 02_指标口径.md 第 3 节） |
| channel_type | NVARCHAR | 付费拉新 / 付费品牌词 / 免费流量 |
| pageviews | INT | 这次访问看了几个页面 |
| landing_page | VARCHAR | 落地页（第一个页面） |
| is_bounce | INT | 1 = 只看了 1 个页面就离开 |
| reached_products … reached_thank_you | INT | 1 = 到达过商品列表 / 商品详情 / 购物车 / 配送 / 支付 / 下单成功 |
| product_page / billing_page | VARCHAR | 看过的商品详情页 / 支付页版本 |
| has_order / order_id | INT | 是否下单、订单编号 |
| revenue_usd / gross_profit_usd | DECIMAL | 这次访问带来的收入、毛利（没下单为 0） |

### dwd.fact_pageview（一行 = 一次浏览）

pageview_id（主键）、session_id、viewed_at、pageview_url、page_seq（访问中的第几个页面）、page_type（页面类型）

### dwd.fact_order（一行 = 一笔订单）

order_id（主键）、session_id（唯一）、user_id、ordered_at、order_date、order_month、primary_product_id、items_purchased、revenue_usd、cogs_usd、gross_profit_usd、refunded_items、refund_amount_usd

### dwd.fact_order_item（一行 = 订单里的一件商品）

order_item_id（主键）、order_id、product_id、is_primary_item、ordered_at、price_usd、cogs_usd、is_refunded、refund_amount_usd、refunded_at

### dwd.dim_product（商品）

| product_id | 商品 | 上架时间 | 售价 | 成本 | 毛利率 |
|---|---|---|---|---|---|
| 1 | The Original Mr. Fuzzy | 2012-03-19 | $49.99 | $19.49 | 61.0% |
| 2 | The Forever Love Bear | 2013-01-06 | $59.99 | $22.49 | 62.5% |
| 3 | The Birthday Sugar Panda | 2013-12-12 | $45.99 | $14.49 | 68.5% |
| 4 | The Hudson River Mini bear | 2014-02-05 | $29.99 | $9.49 | 68.4% |

## 汇总层

| 表 | 粒度 | 用途 |
|---|---|---|
| dws.session_daily | 日期 × 渠道 × 设备 × 新老访客 × 落地页 | 流量、转化、漏斗的所有汇总 |
| dws.order_item_monthly | 下单月份 × 商品 × 是否主商品 | 商品销量、收入、退款 |
