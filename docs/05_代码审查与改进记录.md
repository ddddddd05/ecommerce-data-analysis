## 改的过程中顺带发现的两个问题

- **热力图的分母**：原来用“这个小时有访问的天数”做分母，某天某小时恰好 0 次访问时那天会被漏掉、平均值偏高。改为“这一年里有几个周一 / 周二……”。本数据每个小时都有访问，结果没有变化，但口径更严谨。
- **导入后统计信息缺失**：改成 NVARCHAR 后第一次全量运行，质量检查从约 30 秒变成约 200 秒；单独重跑只要 32 秒。原因是刚导入的表没有统计信息，优化器按错误行数选了执行计划。导入后加了 `UPDATE STATISTICS ... WITH FULLSCAN`，全量运行恢复到约 88 秒。
